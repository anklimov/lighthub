На контроллере может быть активизирован режим доступа к шине MODBUS через TCP/IP
Данный режим может быть полезен для удаленного управления/перепрошивки устройств, которыми управляет контроллер в режиме Modbus-Master
Доступ обеспечивается как через протокол UDP так и через TCP с использованием стандартного порта 502

Для активации такого шлюза, надо перекомпилировать прошивку со следующими опциями (см [[опции_компиляции]])
<code>
-D IPMODBUS
</code>

Будет использован порт Modbus v1 и его настройки. Изменить настройки можно следующими директивами:
<code>
-D MODBUS_SERIAL_PARAM=SERIAL_8N1
-D MODBUS_SERIAL_BAUD=9600
</code>
В примере выше даны настройки по-умолчанию
