====== LightServ ======

Это компактный сервер под управлением OS Ubuntu 18
Идеален в качестве домашнего сервера. Не имеет движущихся частей, бесшумен, мощность более чем достаточна для быстрой работы всех серверных приложений, обслуживающих дом.
 
[[http://ali.pub/488bry|NUC мини-ПК Celeron J3160 комппактный Четырехъядерный безвентиляторный  Intel i210AT c поддержкой AES шифрования]] пригодится, если на нем планируете запустить мощный роутер/файрволл с поддержкой VPN

[[http://ali.pub/488cbs|Celeron J1800 J1900 4 ядра 4 Gigabit LAN]] (вариант попроще)

Рекомендуемая конфигурация: 8Gb RAM, 64Gb SSD

В представленном образе предустановлены следующие компоненты:

* Web cервер Apache
* PHP7
* VirtualBox
* Web консоль под VirtualBox
* Images файрволов pfSence, Mikrotik Cloud Hosted Router (без лицензии)
* Image контроллера беспроводного Wifi Cambium
* Docker
* Консоль управления Docker-ом Portainer
* Hassio (Home Assistant, развернутый в докере)c плагином Web Configurator
* NodeRed
* MQTT брокер Mosquitto
* Контроллер беспроводного WiFi TPLink (omada), развернутый как Docker контейнер

Минимальные требования: 2Cores Celeron 1600 64 bit с поддержкой VT-x, 4Gb Ram, 32Gb HDD/SDD
После заливки, сервер готов к использованию совместно с контроллером LightHub 

Для заливки сервера необходимо:

* [[https://www.clonezilla.org/downloads/download.php?branch=stable|Скачать образ Clonezilla]]
* Записать его на Flash (min 1Gb) (для windows пользователей можно исп. ПО rufus)
* Загрузить сервер с данной флеш
* Выбрать режим восстановления диска с WebDav сервера (ответы на некоторые вопросы можно найти [[https://any-key.net/clonezilla-instrukciya-na-russkom/]])
* В качестве URL сервера ввести https://files.lazyhome.ru/remote.php/webdav
* Логин - lightserv 
* Пароль - спрашивайте в группе телеграм
* Имя образа: 2019-12-12-lightserv

После завершения заливки, попробуйте перезагрузить сервер
После успешной загрузки, зайдите на страницу http://<IP-адрес-сервера> 

(IP адрес выдается динамически вашим роутером и его можно посмотреть в настройках DHCP сервера вашего роутера. И тут же привязать к MAC адресу, чтобы он более не менялся. Учтите, что DHCP работает только для порта LAN1)

Если все хорошо, вы увидите такой экран:

Далее, он будет являться точкой входа в ваш сервер

после заливки, каждая из программ, требующая авторизации, по-умолчанию, имеет пользователя admin с паролем admin (или admin123 там, где политики требуют более длинного пароля)


Также, данный логин-пароль используется для доступа по ssh


Первое, что необходимо, заменить пароли во всех системах на свои собственные


Также, надо заменить пароль пользователя virtualbox и указать его в /var/www/html/phpvirtualbox/config.php


''nano /var/www/html/phpvirtualbox/config.php''


Для замены паролей вебинтерфейсов - используйте соответствующие настройки этих интерфейсов
Для замены паролей пользователей  Linux используйте команду passwd
